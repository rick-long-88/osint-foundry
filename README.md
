# osint-foundry

A local-first OSINT investigation program that replays the **osintpilot**-style
agent pipeline (digital footprint, breach intelligence, public records,
identity resolution, web archive) while reusing the passive-recon sources from
the **osint-map** toolkit. Emits sourced, confidence-scored intelligence
reports plus **GeoJSON** for local 3D-globe visualisation with
[bilawalsidhu/gods-eye-view](https://github.com/bilawalsidhu/gods-eye-view).

## Quick start

```bash
pip install -e .
osint investigate example.com
```

The runner executes each stage as an isolated collector. A failed source keeps
its last-good payload and is retried on a later run rather than aborting the
whole investigation.

## Subcommands

| Command | Description |
| --- | --- |
| `osint investigate <target>` | One-shot investigation (all stages) |
| `osint stages` | List available collector stages |
| `osint geo <report.json> --out f.geojson` | Convert a report to GeoJSON for gods-eye |
| `osint report <report.json>` | Pretty-print a JSON report |

## Pipeline stages

| Stage | Collector | What it surfaces |
| --- | --- | --- |
| `recon` | `DigitalFootprintCollector` | DNS, RDAP, certificate transparency, IP geolocation, GitHub hints |
| `breach` | `BreachIntelCollector` | HIBP breach registries, CVE details, CISA KEV entries |
| `records` | `PublicRecordsCollector` | SEC EDGAR filings, OpenCorporates companies, WHOIS registrant data |
| `identity` | `IdentityResolutionCollector` | Email/domain correlation, alias resolution, IP cross-reference |
| `archive` | `WebArchiveCollector` | Internet Archive CDX timeline for the target |
